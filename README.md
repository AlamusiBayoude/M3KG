# M³KG

[中文](#中文简介) | [English](#english-overview) | [Open website](https://alamusibayoude.github.io/M3KG/)

## 中文简介

M³KG 是一个面向蒙药知识组织、证据检索与关联发现的先验知识驱动框架。平台将蒙药饮片、蒙医术语、药性属性、基源分类单元及跨表映射关系进行结构化建模，形成可查询、可追溯、可推展的蒙药知识体系。网站支持多维筛选、全文检索、药物对比、知识图谱邻接探索及药性关联可视化。

## English overview

M³KG is a prior knowledge-guided framework for organizing, retrieving and discovering knowledge about Mongolian medicinal pieces. It structures medicinal pieces, Mongolian medicine terminology, traditional properties, pharmacognostic origins and cross-table mappings into a traceable and extensible knowledge system. The web explorer supports faceted search, full-text retrieval, medicine comparison, neighborhood graph exploration and interpretable property visualization.

## Website deployment

This repository is a static GitHub Pages build. Data required by the interface are stored as JSON shards under `data/`; no server process is required. The reproducible local database and API scripts are retained in `backend/`.
